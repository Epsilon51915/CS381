# Tyler Carroll CS 381 AS6 Readme

## Usage

### Fetch repository
    git submodule add 
    git submodule --init --recursive

### Compile program:
    **IMPORTANT: DELETE ANY PREVIOUSLY EXISTING BUILD FOLDER**
    `mkdir build`
    `cd build`
    `cmake ..`
    `make`

### Run program
    `./as6`

### Controls:
    A/D - Change the direction that the penguin is spinning in.
    Mouse controls for volume slider for music.

### How To Play:
    Pressing A/D inverts the penguin's direction of rotation, but makes the penguin rotate faster!
    Score increases based on the time spent surviving multiplied by the penguin's rotation speed
    Balance between making the penguin change directions without seeing you and surviving for as long as possible to maximise points!
